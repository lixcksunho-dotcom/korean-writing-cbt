# kbspass 구축 실행 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** kptest 저장소를 복제해 KBS한국어능력시험 전용 사이트(kbspass)를 만들고, 브랜드·사업자·결제·DB가 환경변수로 갈리게 해서 어머니 사업자로 열 수 있는 상태까지 가져간다.

**Architecture:** 복제 후 실용글쓰기 흔적을 걷어내고, 하드코딩된 브랜드·사업자 정보를 설정 한 곳으로 모은다. 결제는 '아직 안 엶' 상태를 정식으로 지원해서, 포트원 심사가 끝나기 전에도 사이트를 무료로 열 수 있게 한다.

**Tech Stack:** Next.js 16(App Router) · React 19 · TypeScript · Tailwind 4 · Supabase · PortOne V2 · Playwright

**Spec:** `docs/superpowers/specs/2026-08-27-kbspass-design.md`

## Global Constraints

- 새 저장소 위치: `C:\Users\선호\kbspass` (kptest와 형제 폴더)
- 사이트 이름은 **kbspass**, 브랜드 표기는 **KBS한국어패스**. '실글패스'가 한 군데도 남으면 안 된다
- 프로그램은 `kbs` 하나만 남긴다. `silyong`은 코드·문항·설정에서 제거
- 사업자 정보는 어머니 사업자. 실제 값이 오기 전까지 **비워 두되 화면이 깨지지 않아야** 한다
- 결제는 포트원 심사 전까지 열지 않는다. 결제 버튼이 '준비중'으로 남고 무료 회차는 정상 동작해야 한다
- 검사 스크립트(`check:*`)는 전부 복제하고 통과해야 한다

```js
// 남의 브랜드 이름이 코드에 남아 있는지 본다.
//   npm run check:brand
//
// 복제로 시작한 저장소라 '실글패스'가 곳곳에 남는다. 화면 한 군데만 남아도
// 사용자는 "여기가 어디지?" 하고 닫는다. 사람 눈으로는 96군데를 못 훑는다.
import { execSync } from 'node:child_process'

const FORBIDDEN = ['실글패스', 'kptest', '실용글쓰기', 'silyong']
const results = []
for (const word of FORBIDDEN) {
  let hits = ''
  try {
    hits = execSync(`git grep -n -- "${word}" -- src scripts docs README.md`, { encoding: 'utf-8' })
  } catch {
    hits = '' // git grep은 없으면 exit 1
  }
  const lines = hits.split('\n').filter(Boolean)
  results.push({ word, count: lines.length, sample: lines.slice(0, 3) })
}
const bad = results.filter((r) => r.count > 0)
for (const r of results) {
  console.log(`${r.count === 0 ? 'PASS' : 'FAIL'}  '${r.word}' ${r.count}군데`)
  for (const s of r.sample) console.log(`        ${s.slice(0, 120)}`)
}
console.log(`\n${results.length - bad.length}/${results.length} 통과`)
process.exit(bad.length ? 1 : 0)
```

- [ ] **Step 2: businessInfo를 환경변수 기반으로 바꾼다**

```ts
// 사업자 정보 (전자상거래법 표시의무 + 결제대행사 심사)
//
// 값은 환경변수로 받는다. 저장소에 박아 두면 사업자가 바뀔 때(명의 이전) 코드를 고쳐야 하고,
// 무엇보다 **지어낸 값이 배포되는 사고**가 난다 — 표시의무 항목은 틀리면 법적 문제다.
export const BUSINESS = {
  serviceName: BRAND.serviceName,
  companyName: process.env.NEXT_PUBLIC_BIZ_COMPANY ?? '',
  ceoName: process.env.NEXT_PUBLIC_BIZ_CEO ?? '',
  businessNumber: process.env.NEXT_PUBLIC_BIZ_NUMBER ?? '',
  mailOrderNumber: process.env.NEXT_PUBLIC_BIZ_MAIL_ORDER ?? '',
  address: process.env.NEXT_PUBLIC_BIZ_ADDRESS ?? '',
  email: process.env.NEXT_PUBLIC_BIZ_EMAIL ?? '',
  phone: process.env.NEXT_PUBLIC_BIZ_PHONE ?? '',
  privacyOfficer: process.env.NEXT_PUBLIC_BIZ_PRIVACY_OFFICER ?? '',
  domain: BRAND.domain,
} as const

/** 비어 있는 표시의무 항목. 화면과 검사가 같은 판정을 쓴다. */
export function MISSING_FIELDS(b: typeof BUSINESS): string[] {
  const required: [keyof typeof BUSINESS, string][] = [
    ['companyName', '상호'], ['ceoName', '대표자'], ['businessNumber', '사업자등록번호'],
    ['mailOrderNumber', '통신판매업 신고번호'], ['address', '사업장 주소'],
    ['email', '고객센터 이메일'], ['phone', '고객센터 전화'],
  ]
  return required.filter(([k]) => !b[k]).map(([, label]) => label)
}
```
