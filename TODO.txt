[1단계] 배포 세팅 (가장 먼저)
------------------------------------------------------
1. [완료] 도메인 구매 → kptest.cloud

2. GitHub 저장소 생성
   - github.com 접속 → New repository
   - 이름: korean-writing-cbt (Private 권장)

3. 프로젝트 GitHub에 올리기
   - 터미널에서 korean-writing-cbt 폴더로 이동 후:
     git init
     git add .
     git commit -m "init"
     git remote add origin https://github.com/본인아이디/korean-writing-cbt.git
     git push -u origin main

4. Vercel 배포
   - vercel.com 접속 → GitHub 계정 연결
   - 방금 만든 저장소 import
   - 환경변수 입력 (.env.local 내용 전부):
       NEXT_PUBLIC_SUPABASE_URL
       NEXT_PUBLIC_SUPABASE_ANON_KEY
       SUPABASE_SERVICE_ROLE_KEY (결제 구독 발급에 필수, 서버 전용)
       ANTHROPIC_API_KEY
       ADMIN_EMAILS
       NEXT_PUBLIC_TOSS_CLIENT_KEY (나중에 실키로 교체)
       TOSS_SECRET_KEY (나중에 실키로 교체)
   - Deploy 클릭

5. 도메인 연결
   - Vercel 프로젝트 설정 → Domains → kptest.cloud 추가
   - Vercel이 알려주는 DNS 값을 가비아 DNS 설정에 입력
   - 적용까지 최대 24시간 (보통 10~30분)


[2단계] 소셜 로그인 연동
------------------------------------------------------
6. 구글 로그인 연동
   - Google Cloud Console(console.cloud.google.com) 접속
   - 새 프로젝트 생성 → OAuth 2.0 클라이언트 ID 발급
   - 승인된 리디렉션 URI: https://itzhfbsbwuoedncnjhzt.supabase.co/auth/v1/callback
   - Client ID, Client Secret 복사
   - Supabase 대시보드 → Authentication → Providers → Google 활성화 후 붙여넣기

7. 네이버 로그인 연동
   - 네이버 개발자센터(developers.naver.com) 접속
   - 애플리케이션 등록 → 네아로(네이버 아이디로 로그인) 선택
   - 콜백 URL: https://itzhfbsbwuoedncnjhzt.supabase.co/auth/v1/callback
   - Client ID, Client Secret 복사
   - Supabase → Authentication → Providers → Naver 활성화 후 붙여넣기


[3단계] 결제 연동 (토스페이먼츠)
------------------------------------------------------
8. 토스페이먼츠 실 계정 발급
   - tosspayments.com 접속 → 사업자 가입
   - 사업자등록번호 필요 (개인사업자 or 법인)
   - 심사 통과 후 실 키 발급 (test_ck_ → 실제 키로 교체)
   - .env.local 및 Vercel 환경변수 업데이트:
       NEXT_PUBLIC_TOSS_CLIENT_KEY=live_ck_...
       TOSS_SECRET_KEY=live_sk_...

9. Anthropic API 크레딧 충전
   - console.anthropic.com 접속 → Billing → 크레딧 충전
